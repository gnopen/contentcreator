## ✅ Quality Check Pasca-Generate

Untuk tiap visual yang Anda generate, cek:

- [ ] **Cream background dominan** (bukan putih bersih)
- [ ] **Mustard sebagai single accent** (tidak banyak warna terang)
- [ ] **Hand-drawn ink line art mood** (bukan flat-vector tech-y)
- [ ] **Asymmetric composition** dengan ruang putih jelas
- [ ] **Topographic contour texture** ada tapi sangat samar
- [ ] **NO TEXT** — kalau ada huruf nyasar, regenerate
- [ ] **Aspect ratio sesuai** target platform
- [ ] **Konsisten dengan visual lain di set yang sama** (kalau Anda generate Set A semua, pastikan stylenya match)

## 💡 Tips Variasi

- Kalau hasil terlalu kosong/minimal: tambah `"Add 2-3 more small supporting sketch details in the corners, like marginalia in an explorer's notebook."`
- Kalau hasil terlalu padat: tambah `"Even more minimal. Reduce supporting elements by half. More breathing space."`
- Kalau warna mustard kurang dominan: tambah `"Make the mustard yellow accent block larger and more prominent — should be the first thing the eye sees."`
- Kalau terlalu colorful: tambah `"Use only ink black and mustard yellow. No earth tones at all in this version."`
