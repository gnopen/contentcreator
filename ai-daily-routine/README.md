# AI Daily Routine — A Field Manual

A 30-day Instagram + TikTok carousel series about agentic AI workflows, published in an editorial Field Manual aesthetic distinct from the Anthropic / OpenAI / generic tech-startup visual languages.

## Brand Identity

- **Name**: AI Daily Routine
- **Handle**: `@aidailyroutine` (IG + TikTok)
- **Tagline**: A field manual for working with intelligent systems daily.
- **Positioning**: Slow, premium, technical-journal feel. Counter-positioned against hype content. Build trust over 30 chapters, convert to Agentic + Skills class.

## How to Use

### Render a Chapter as Instagram Carousel

1. Open [claude.ai](https://claude.ai) → start new chat
2. Paste contents of `02-master-design-prompt.md` once — Claude acknowledges the design system
3. Paste contents of any `chapters/chapter-XX.md` → Claude renders an HTML artifact with 6 slides (1080×1350 each)
4. Screenshot each slide from the artifact preview
5. Upload to Instagram as carousel post

### Posting Schedule

- **TikTok**: 2x/day (11:00 + 20:00 WIB) — animated version of carousel
- **IG Feed**: 1x/day (13:00 WIB) — carousel
- **IG Reels**: 1x/day (13:30 WIB) — same content, optimized for IG
- **IG Stories**: 3-5x/day — "Today's Page" mini-frames
